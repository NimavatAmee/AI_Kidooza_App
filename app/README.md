# App & Backend Core

This directory contains:
- **Backend API Server:** Node.js + Express + Prisma + PostgreSQL (Auth, child profiles, session tracking, safety filters, AI voice proxy).
- **Shared Logic & Types:** Contracts and schemas shared between mobile, web, and admin.
- **Web Companion:** Future web version for cross-platform access.

*Implementation starts in Phase 3 after Phase 1 (2D Character) and Phase 2 (Mobile UI) validation.*
